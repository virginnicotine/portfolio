# Портфолио auramalayya: инструкция

## Что внутри
- `index.html`: весь сайт (HTML + CSS + JS в одном файле)
- `assets/`: сюда кладём картинки и музыку

## Как открыть
Дважды кликни на `index.html`, и сайт откроется в браузере. Редактировать можно в VS Code.

## Где менять заглушки
Всё в самом конце `index.html`, в блоке `НАСТРОЙКИ: меняй только здесь`.

### 1. Ссылки
Замени `"#"` на настоящий адрес:
```js
const LINKS = {
  github:   "https://github.com/твой-ник",
  telegram: "https://t.me/твой-ник",
  factory:  "https://cr307869.tw1.ru",
  novel:    "https://t.me/...",       // новелла
  ecto:     "https://github.com/...", // Ecto Stats
};
```
Если оставить `"#"`, кнопка просто никуда не ведёт. Ссылки с `http` сами открываются в новой вкладке.

### 2. Картинки
1. Положи файл в папку `assets/`, например `assets/avatar.jpg`.
2. Впиши путь:
```js
const IMAGES = {
  avatar:  "assets/avatar.jpg",
  factory: "assets/factory.jpg",
  novel:   "assets/novel.jpg",
  ecto:    "assets/ecto.jpg"
};
```
Аватарка встанет в шапку и в терминал (с крутящейся обводкой), остальные картинки в карточки проектов.
Советы: аватарка квадратная ~400x400, скриншоты до 1200 px по ширине, формат jpg или webp. Картинки автоматически становятся чёрно-белыми. Чтобы оставить цвет, в CSS у `.ava img` и `.ph img` удали `filter:grayscale(1) contrast(1.1)`. На скриншоте завода и БД закрой или размой данные.

### 3. Музыка
1. Положи mp3 в `assets/music.mp3`.
2. Впиши:
```js
const MUSIC = { src: "assets/music.mp3", title: "Название трека" };
```
Плеер слева внизу. Автозапуска нет (браузеры его блокируют), музыка включается кнопкой. Бери трек без авторских прав, раз сайт публичный.

### 4. Статус в терминале
```js
const STATUS = "Coding / Gaming (CS2, Brawl Stars)";
```

## Интро: текст песни, дроп и открытие сайта
При входе на сайт сначала идёт чёрный экран с кнопкой Enter. После нажатия играет трек, а на экране по очереди появляются строки текста. На дропе вспышка, тряска, и сайт открывается, а песня продолжает играть дальше без перезапуска. Кнопка Skip в углу сразу прыгает на дроп.

Настройка в блоке `INTRO` (рядом с `MUSIC`):
```js
const INTRO = {
  enabled: true,   // false = сайт без интро
  drop: 12.5,      // секунда трека, на которой дроп
  bpm: 120,        // темп трека, текст пульсирует в такт (0 = выключить)
  beatOffset: 0,   // секунда первого бита
  lines: [
    { t: 0.6,  text: "первая строка" },
    { t: 2.4,  text: "вторая строка" }
  ]
};
```
Как настроить:
1. Положи трек и впиши его в `MUSIC`.
2. Включи трек в любом плеере и запиши секунды, когда начинается каждая строка. Впиши их в `t`.
3. Секунду, когда бьёт дроп, впиши в `drop`. Последняя строка должна появиться до неё.
4. Темп (bpm) можно узнать в любом онлайн-определителе BPM.
5. Сохрани и обнови страницу, потом подкрути тайминги.

Без трека (`src: ""`) интро работает «вхолостую»: строки идут по таймеру, звука нет. Так можно проверить анимацию.

## Как менять тексты
Открой `index.html` и найди нужную фразу через Ctrl+F:
- описания проектов: название проекта (Factory, Ecto Stats и т.д.)
- блок «I am / I make / I also do»: ищи `I make`
- список технологий в бегущей строке: переменная `it`
- строки в терминале: переменная `lines`

## Как поменять цвета
В начале файла, блок `:root`: `--bg` (фон), `--fg` (текст), `--metal` и `--chrome` (металлические градиенты).

## Как выложить в сеть
- **Timeweb:** загрузи содержимое папки (index.html и assets) в корень сайта, обычно `public_html`.
- **GitHub Pages:** создай репозиторий, залей файлы, в Settings > Pages включи публикацию из ветки main.

## Важно
Шрифты подгружаются с Google Fonts, поэтому нужен интернет. Если шрифты не загрузятся, сайт покажет запасные.
